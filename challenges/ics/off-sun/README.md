# Off-Sun

**Category:** ICS
**Difficulty:** Hard
**Author:** Jebediah Kerman

## Description (what the competitor will see)

Ten hours before we lost the main bus, the solar arrays quietly walked off-sun and our
power budget went with them. Ops swears no one touched the pointing controls — the
engineering console shows only routine setpoint tweaks, all inside limits.

But the arrays don't move themselves. Something on the control segment was talking to
the array controller, and it was very careful to look like it belonged there.

We pulled a capture off the segment span port before the reboot. Find who was really
driving the arrays, and figure out what they left behind.

## Files Provided

- `array_ctrl.pcap` — packet capture from the solar-array control network segment
