# Last Mile

**Category:** ICS
**Difficulty:** Medium

**Author:** Voyager 1

*(3/3 of the "Lateral Drift" sequence — requires access gained in **Lateral Drift**.)*

## Description

You finally reach the KEEPER OF TOMORROW's engineering workstation, and now you can see what Rootkit
has been doing with it: he has taken over the Kalium refinery line and is enriching the ship's fuel for
himself, one centrifuge run at a time. You cannot force him off the controls from here, but you can take
the line down. The controller's commissioning paperwork is on the workstation, and nobody ever closed the
last item on its checklist. Work out what that unfinished item was meant to prove, and see it through.

## Files Provided

None — this is a live-service challenge, reached by pivoting from the access gained in Lateral
Drift.

## Connection

Discover the Modbus/TCP endpoint via the engineering workstation gained in Lateral Drift. The
workstation's Documents panel covers the rest.
