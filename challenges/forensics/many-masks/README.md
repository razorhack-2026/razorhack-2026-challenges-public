# Many Masks

**Category:** Forensics  
**Difficulty:** Hard  
**Author:** Jebediah Kerman  

## Description

Salvage pulled one file off the derelict's data core before the racks lost power. The manifest
listed it three times, under three different names, with three different sizes — and only this
survived.

Our tooling says it is an image and refuses to discuss it further. The caption it displays
starts something it never finishes.

Whatever the crew were hiding, they did not hide it in three files.
