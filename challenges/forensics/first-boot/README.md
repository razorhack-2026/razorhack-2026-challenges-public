# First Boot

**Category:** Forensics · **Difficulty:** Medium · **Author:** Andy Roid

A new Waste Systems crew member's console, a few days after a friendly
"onboarding helper" walked them through setting it up. Nobody has
reported anything wrong, but the digester's sterilization logs look off.

We pulled the registry hives, the Prefetch folder and the Amcache off the
console. Work out what the helper actually had them run, and what it
left behind.
