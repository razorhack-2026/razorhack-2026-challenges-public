# Tool Call Trail

**Category:** Forensics
**Difficulty:** Medium
**Author:** Andy Roid

## Description

Our listening post intercepted a fragment of the enemy mining ship ICARUS's
internal comms — hundreds of routine "mining" sessions between its onboard
subsystems. Somewhere in the noise it stopped mining rock and locked onto
something it should have left alone. Find out what it was really hunting.

## Files Provided

- `intercept.pcap` — packet capture of the ship's internal subsystem traffic
  (cleartext HTTP, ~450 sessions, ~5 MB)

No network required.
