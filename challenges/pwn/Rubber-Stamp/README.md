# Rubber Stamp

**Category:** Pwn
**Difficulty:** Medium
**Author:** Lt. Rico Kopernicus

## Description

If you didn't know, to get anything done you have to get it approved through RazorPowerCo's
form portal, Rubber Stamp. Man, I hate paperwork. Your sink drain is clogged? Fill out the
form. You wanna take off for a day to rest your overworked mind? Fill out the form. Even if
you just want another soap bar for the shower, you have to fill out the form and wait for
approval. But somehow, all the higher-ranking officers get their stuff done almost immediately.
There has to be some secret way they get things approved WAY faster than we can. I managed to
pull Rubber Stamp's source code using my IT creds (I still don't know why they let me access the
main RPC code base). See if you can find a way to bypass approval and get us some goodies.
