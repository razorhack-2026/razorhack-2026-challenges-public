# WaveCode 2

**Category:** Misc
**Difficulty:** Medium
**Author:** Lt. Niko Copernicus

## Description

We managed to get a lock on the navigation beacon's signal, but it just started transmitting a new tone. The signal appears to use a deprecated data encoding that represents messages as a sum of sine waves. I dug up the encoding specification in `encoding.md`, see if you can decode the new transmission.

## Files Provided

- `beacon.csv` — samples of the total waveform (`timeSeconds,amplitude`).
- `encoding.md` — the WaveCode encoding and packet specification.
