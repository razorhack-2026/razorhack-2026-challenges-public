# Cosmic Calibration

**Category:** Misc
**Difficulty:** Easy
**Author:** WALL-D
**Series:** Calibration Sequence

## Description

    A strange signal has turned off the ships autopilot. In fact, it seems like the entire KEEPER OF TOMORROW's alignment has been thrown off. Luckily, the great minds at RASA had thought about this and created a calibration sequence to get the ship back on track. Unluckily, it doesn't seem to be a simple button you can press.

## Files Provided

- A hosted browser panel, linked on the challenge page. Works on any OS.
- `calibration_sequence` — the same panel as a Linux x86-64 executable.
- `RUN.md` — how to run either one.

To run the executable from a terminal:

    chmod +x calibration_sequence
    ./calibration_sequence

It opens a graphical window, so you need a desktop / X session.
