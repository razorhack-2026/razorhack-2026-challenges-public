# Blind Pilot

**Category:** Misc  **Difficulty:** Hard  **Author:** Tyrian Sol

## Description

The nav computer fried as we entered the belt. Every rock out here drifts in a straight line, and our short-range radar can only see the cells right next to the hull. The jump gate is on the far side of the field. Fly us out, pilot.
