# WaveCode 1

**Category:** Misc
**Difficulty:** Easy
**Author:** Lt. Niko Copernicus

## Description

Lost in space, your crew has picked up a RazerPowerCo navigation beacon.
Before the ship can lock on, you need to identify the strongest frequency
component in the recorded waveform.

Report its frequency in hertz, rounded to the nearest whole number. Submit
that decimal integer inside the standard flag wrapper (lowercase `flag`
followed by braces), with no units, spaces, or leading zeros.

## Files Provided

- `beacon.csv` — samples of the total beacon waveform, with columns `timeSeconds` (seconds) and `amplitude` (arbitrary units).
