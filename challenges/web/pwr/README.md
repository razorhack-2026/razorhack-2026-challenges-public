# Reactor Access

Category: Web  
Difficulty: easy

## Description

The Keeper of Tomorrow's reactor controls are locked at player clearance. Investigate the control interface, gain administrator access, and trigger SCRAM to recover the core token.

The flag is returned by `POST /api/reactor/scram` once you are authenticated as an administrator.
