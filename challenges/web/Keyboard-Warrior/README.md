# MED BAY: Keyboard Warrior

**Category:** Web  **Difficulty:** Hard  **Author:** Tyrian Sol

## Description

As one of your tasks on this ship, you will be writing many logs and reports that will need to be done quickly and with few errors. Complete a four-level typing assessment. Each prompt grows longer and more difficult, with higher speed and accuracy targets. Pass the final assessment to receive your clearance report.
