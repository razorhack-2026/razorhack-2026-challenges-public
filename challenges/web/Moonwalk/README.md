# Moonwalk

**Category:** Web  **Difficulty:** Medium  **Author:** Tyrian Sol

## Description

Dexterity and quick reflexes are important skills for a valiant member of this ship. Test your reflexes in a fast-paced exercise: press the key from 1 to 4 that matches the next asteroid. The pace increases as you progress, and a single mistake ends the run. Complete the course to receive your clearance.
