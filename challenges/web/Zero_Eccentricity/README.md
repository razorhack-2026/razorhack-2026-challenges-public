# Zero Eccentricity

**Category:** Web
**Difficulty:** Medium
**Author:** Voyager 1

## Description

The station's autopilot died somewhere past the last relay, and the NAV-7 console wants the
orbit insertion traced by hand. Hold the button, draw one loop around the planet, and the burn
computer will judge it.

The flight manual says a steady hand can do it. Nobody on this crew has a hand that steady.
