## Reporting Guidelines

- Report every security incident, even ones that seem minor.
- Badge-related incidents should also be forwarded to the Badge Office.
- Don't include personal details beyond what's needed to describe the incident.
- "It was probably nothing" is not a valid reason to skip a report.
