# Spill the Beans

**Category:** Web
**Difficulty:** Easy
**Author:** Lt. Rico Kopernicus

## Description

We need to decommission the autonomous drilling rig on 2000 SY178, but I can't
access the console's secrets to see if we need to wipe anything. Something must
have corrupted the admin login to its terminal. If I remember correctly, the
software was written in PHP by some intern years ago, so honestly, there's probably
some vulnerability still lingering in the code. See if you can extract the secrets
and find anything we need to take care of.
