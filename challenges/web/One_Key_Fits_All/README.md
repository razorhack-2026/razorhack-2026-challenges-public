# One Key Fits All

**Category:** Web
**Difficulty:** Medium
**Author:** Voyager 1

## Description

A ransomware gang calling itself VoidCrypt hit RazerPowerCo's IT systems last
week. OT itself wasn't touched, but operations were shut down as a
precaution while the field office sorts out what's locked.

VoidCrypt runs its own victim "support" portal where affected
organizations can check their payment and key-release status. Its address is
the `portal` entry in this challenge's connection info.

Your organization's case id is **b7f39d21a6048ce5**. Start there.

Separately, one of the actual affected RazerPowerCo machines is reachable over
SSH at the `ssh` address in the connection info, as user `rpc_tech` with
password `F13ldRecovery!42`.

Everything you need to get your files back is reachable from those two
places.
