# Too Many Astronauts in the Station

## Author: Lt. Niko Copernicus

## Category: Cryptography

## Difficulty: Hard

## Description

Lt. Copernicus apparently has a message for you, but he wouldn't say anything about it. When I tried getting more details, he said "SHHHHH THEYRE LISTENING". He said that several members of the crew, including him, have a piece of the message and you have to figure out how to put them together. Go talk to these people and see if you can get the message out of them:

- Peri Helion
- Grace
- WALL-D
- Voyager 2
- Tyrian Sol
- Lt. Niko Copernicus
- Lt. Rico Kopernicus (no relation)
- Andy Roid
- Davie Bowman
