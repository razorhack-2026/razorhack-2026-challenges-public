**Category:** Steganography

## Description

A shift log entry recovered from crew member cm-0417's backup partition
reads completely routine — nothing flagged, nothing out of place. Except
the phrasing is just a little *off*. Every sentence, every single one.

Maybe that's not a coincidence.
