# Fried Readout

**Category:** Reverse Engineering
**Difficulty:** Easy
**Author:** Andy Roid

## Description

The swarm's Harvester is coming straight for us, screened by a ring of escorts.
PD-1 can take anything it throws, but in sixty seconds the Harvester hits the
hull, and that's the end of the ship.

Someone fried the fire-control sensor feed. The Harvester's integrity readout
is a dead bar with no numbers on it, and nothing we fire seems to move it.
Bring down the Harvester and every escort and the command-link key
reassembles. Fire control is still yours: override whatever you need to.

Run `fried_readout` on your Kali box (it needs an X display). The game runs
locally; nothing to connect to.

## Files Provided

- `fried_readout` -- the PD-1 fire-control game (Linux x86-64)
- `SHA256SUMS` -- checksum of the file above

## Controls

Arrows or A/D to move, Space to fire, P to pause, R to relaunch after a loss.
