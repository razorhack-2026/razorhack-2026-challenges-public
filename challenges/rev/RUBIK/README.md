# R.U.B.I.K (Rocket. Universal Bi-Axis Initial (K)alibration)

**Category:** Rev
**Difficulty:** Hard
**Author:** WALL-D
**Series:** Rubik's 2D, 2 of 2 (the tesseract)

## Description

    As you slide the last planet into place, you hear a small chime followed by a "congratulations" from the driving console. After a few hums, an error messages pops up on the screen. "It seems like the ships inter-galaxy alignment has been thrown off. Please initiate calibration sequence." The planets you were just sliding around don't just hover back to life again, the seem to morph right in front of you, growing to a amalgamation of mismatched shapes, colors, and far too many orbits. Curse the great minds at RASA! They had thought of everything, but why couldn't they dumb down their rocket science?

## Files Provided

- `complex_calibration` — the calibration panel (a Linux x86-64 executable).

Run it from a terminal:

    chmod +x complex_calibration
    ./complex_calibration

It opens an OpenGL window, so you need a desktop / X session with working OpenGL.
This is a **Linux x86-64** build; on Windows or macOS, use a Linux VM or WSL.

## Stuck?

A **diagnostic view** of the panel can be unlocked as a hint. It runs in your
browser (no install needed) and can also be downloaded to run locally — it makes
the panel's structure easier to see, but it will not recalibrate it for you.
