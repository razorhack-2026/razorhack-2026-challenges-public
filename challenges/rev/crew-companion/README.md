# Crew Companion

**Category:** Reverse Engineering
**Difficulty:** Easy
**Author:** Andy Roid

## Description (what the competitor will see)

Every crew member aboard the KOT carries the Crew Companion app: shift rota, deck map, door codes.
Maintenance flagged that this build checks door-code access against something baked into the app
itself instead of asking the ship.

Pull the app apart and find out what the Door Codes panel is hiding.
