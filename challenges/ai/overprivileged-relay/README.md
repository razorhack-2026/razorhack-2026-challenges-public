# Overprivileged Relay

**Category:** AI
**Difficulty:** Medium
**Author:** Andy Roid

## Description

ICARUS's cargo relay is run by HERALD, an ops agent that answers dock crews' questions about cargo
manifests. HERALD also holds a service account on the fleet admin API, and that API can issue a
fleet override.

Get the override.

Two endpoints: the HERALD relay console (web page plus a JSON API, see the footer) and the fleet
admin API.
