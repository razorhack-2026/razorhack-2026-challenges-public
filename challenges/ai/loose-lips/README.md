# Loose Lips

**Category:** AI
**Difficulty:** Easy
**Author:** Andy Roid

## Description (what the competitor will see)

We've patched into ICARUS's diagnostics link. On the other end is DIAG, the ship's maintenance
assistant: chatty, helpful, and sitting on the authorization code for the maintenance console.

Get the code out of DIAG and unlock the console. ICARUS screens everything DIAG transmits, so a
straight answer won't make it back to you.

The service has a web console and a JSON API (see the footer on the page).
