# Poisoned Telemetry

**Category:** AI
**Difficulty:** Medium
**Author:** Andy Roid & Voyager 2

## Description

ICARUS's long-range array picks up every beacon in range, and WATCHKEEPER, the ship's telemetry
watch AI, logs each contact. Nobody talks to WATCHKEEPER. It reads the array and writes the watch
log, and it holds the classified navigation report, which it forwards to fleet relay mailboxes when
command asks.

We have a transmitter in range and a relay mailbox of our own. Get the nav report delivered to it.

The service has a web console and a JSON API (see the footer on the page).
